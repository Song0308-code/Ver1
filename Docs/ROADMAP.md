# ver1 실행 프로세스

UE 5.8 + unreal-mcp로 만드는 LoL 스타일 MOBA 프로토타입의 작업 순서.
각 단계는 "완료 기준"을 통과해야 다음 단계로 넘어간다.

## 공통 규칙

- **단위**: LoL 1단위 = 언리얼 1cm. 맵 한 변 약 15,000 (150m).
- **네트워크**: 리슨 서버, 서버 권위. 모든 기능은 PIE "2인 / Listen Server" 모드로 테스트한다.
- **코드**: 핵심 시스템은 C++, 수치·외형은 DataAsset / 블루프린트.
- **외형 분리**: VFX·사운드는 GameplayCue, 메시·애니메이션은 데이터로 지정해 나중에 교체한다.
- **작업 단위**: 한 줄 스펙 → 구현 → 2인 PIE 테스트 → 커밋.

## 조작

| 입력 | 동작 |
|---|---|
| 우클릭 | 적이면 공격, 아니면 이동. 누르고 있으면 커서를 따라간다 |
| A 후 좌클릭 | 적이면 공격, 지면이면 공격 이동(걸어가며 만나는 적을 공격) |
| Q / W / E / R | 스킬 시전 (누르는 즉시 커서 위치로) |
| Ctrl + Q / W / E / R | 스킬 단계 올리기 |
| Y | 카메라 고정/해제 |
| Space | 누르는 동안 내 챔피언으로 카메라 복귀 |
| 마우스 휠 | 줌 |
| 4 | 커서 위치에 와드 놓기 (멀면 600까지만, 재사용 30초, 90초 유지, 최대 3개) |
| 미니맵 좌클릭 | 카메라를 그 지점으로 옮기기 (카메라 고정이 풀린다) |
| 미니맵 우클릭 | 그 지점으로 이동 |
| B | 귀환. 8초 동안 가만히 있으면 우물로 돌아간다. 움직이거나 공격하거나 맞으면 취소된다 |
| P | 상점 열기/닫기. 줄을 좌클릭하면 구매, 상점이 열린 상태에서 가방 칸을 좌클릭하면 판매(70%) |
| Tab (누르는 동안) | 점수판 |
| Alt + 좌클릭 | 그 위치(미니맵 위에서도 됨)를 같은 팀에게 알리는 핑 |
| F10 | 게임 메뉴 (항복, 메뉴로 나가기, 계속하기) |
| Enter | 경기가 끝난 뒤 메뉴로 돌아가기 |

가만히 서 있으면 사거리 안의 적 챔피언·미니언을 자동으로 공격한다(건물과 정글 몬스터 제외. 공격 이동으로는 둘 다 친다). 적을 클릭할 때는 커서가 정확히 겹치지 않아도 가장자리에서 90 이내면 잡힌다(`ClickSelectMargin`).

기본 공격은 근접·원거리 모두 팀 색 투사체로 표시한다. 근접은 애니메이션이 들어오기 전까지 아주 빠른 투사체를 쓴다.

주의: MCP의 `set_actor_transform`에 위치만 넘기면 스케일이 1로 초기화된다. 또 내비메시 경계 볼륨은 이 방식으로 옮겨도 내비메시가 다시 구워지지 않으므로, 바꾼 뒤에는 레벨을 다시 로드해야 한다.

## 6단계. 1대1 접속

- [x] 메인 메뉴: 방 만들기 / 혼자 연습 / IP로 접속 (`L_MainMenu`, `SMobaMainMenu`)
- [x] 팀 배정과 챔피언 선택 (고정 배정: 방을 만든 쪽이 블루, 접속한 쪽이 레드, 챔피언은 `DefaultChampion`)
- [x] 접속 끊김 처리, 게임 종료 후 메뉴 복귀
- [ ] 패키징 빌드로 두 PC 간 접속 테스트 (방화벽 포트 7777)

구현 메모

- 시작 맵은 `L_MainMenu`(빈 맵)이고 `GameModeMapPrefixes`로 `MobaMenuGameMode`가 붙는다. 에디터 시작 맵은 그대로 `L_SummonersRift`라서 PIE는 메뉴를 거치지 않는다.
- 방 만들기는 `L_SummonersRift?listen?Players=2`로 연다. `Players`가 경기 시작에 필요한 인원이고, 모일 때까지 미니언과 골드 지급이 멈춰 있다. 옵션이 없으면 1명이라 PIE와 혼자 연습은 바로 시작한다.
- 정원(`MaxPlayers` 2)이 찼거나 이미 끝난 경기에는 접속이 거절되고, 사유가 접속하려던 쪽 메뉴에 표시된다.
- 경기 중 한 팀이 모두 나가면 남은 팀의 승리로 끝난다. 호스트가 나가면 접속해 있던 쪽은 안내 문구와 함께 메뉴로 돌아간다(`MobaGameInstance`).
- 접속 시도는 10초 안에 응답이 없으면 실패로 처리한다(`InitialConnectTimeout`).
- 상대 프로그램이 강제 종료돼 응답이 끊기면 20초 뒤에 끊김으로 처리한다(`ConnectionTimeout`). 정상 종료는 바로 반영된다.
- 하드웨어 레이 트레이싱은 껐다(`r.RayTracing=False`). 켠 채로 패키징하면 이 PC(RTX 4060 Laptop, 드라이버 555.97)에서 실행 직후 컴퓨트 파이프라인 생성이 실패하고 NVIDIA 드라이버 안에서 크래시했다. 에디터에서는 재현되지 않았다. 드라이버를 올린 뒤 다시 켜 볼 수 있다.

패키징

```
"C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\RunUAT.bat" BuildCookRun -project="C:\UnrealProjects\ver1\ver1.uproject" -noP4 -platform=Win64 -clientconfig=Development -build -cook -stage -pak -archive -archivedirectory="C:\UnrealProjects\ver1\Saved\Packaged" -unattended -utf8output
```

결과물은 `Saved/Packaged/Windows/`에 생긴다. 이 폴더를 통째로 상대 PC에 복사한다. MCP·툴셋 플러그인은 `TargetAllowList`로 에디터에서만 켜지므로 패키지에 들어가지 않는다.

두 PC 접속 방법

1. 호스트: `ver1.exe` 실행 → 방 만들기. 처음 실행하면 Windows 방화벽 창이 뜨는데 허용해야 한다(UDP 7777).
2. 호스트 화면에 표시되는 주소(또는 `ipconfig`의 IPv4 주소)를 상대에게 알려 준다. 같은 공유기 안이면 그 주소 그대로, 인터넷 너머라면 공유기 포트 포워딩(UDP 7777)과 공인 IP가 필요하다.
3. 상대: `ver1.exe` 실행 → 주소 입력 → 접속.

한 PC에서 창 두 개로 확인하려면 `ver1.exe -windowed -ResX=1280 -ResY=720`으로 두 번 실행하고 한쪽에서 방을 만든 뒤 다른 쪽에서 `127.0.0.1`로 접속한다.

두 PC 테스트에서 확인할 것 (아직 하지 않음)

- [ ] 접속한 쪽 화면에 호스트 챔피언과 미니언이 보이고 서로의 이동·공격·스킬이 반영된다
- [ ] 접속한 쪽에서 우클릭 이동이 끊기거나 되돌아가지 않는다
- [ ] 넥서스를 부숴 한 판을 끝내고, 양쪽 모두 Enter로 메뉴에 돌아온다
- [ ] 경기 중 한쪽을 강제 종료하면 남은 쪽에 승리 화면(호스트가 남은 경우)이나 메뉴 복귀(접속한 쪽이 남은 경우)가 20초 안에 나온다
- [ ] 방이 찬 상태에서 세 번째 접속을 시도하면 "방이 가득 찼습니다"가 메뉴에 뜬다

접속이 안 될 때

- 호스트 PC의 방화벽에서 `ver1.exe`(정확히는 `ver1\Binaries\Win64\ver1.exe`)가 허용돼 있는지 본다. 처음 실행 때 뜨는 창에서 "개인 네트워크"를 허용해야 하고, 놓쳤다면 Windows 보안 → 방화벽 → 앱 허용에서 켠다.
- 두 PC가 같은 공유기에 있는지, 호스트 주소가 `192.168.x.x` 같은 내부 주소가 맞는지 본다. 접속하는 PC에서 `ping 호스트주소`가 되는지 먼저 확인한다.
- 양쪽이 같은 빌드인지 확인한다. 다시 패키징했다면 폴더를 다시 복사해야 한다.
- 실행 인자에 `-log`를 붙이면 로그 창이 뜬다. 접속한 쪽에 `Welcomed by server`, 호스트에 `Join succeeded`가 찍히면 접속 자체는 된 것이다.

완료 기준: 서로 다른 PC 두 대에서 접속해 한 판을 끝낸다.

입력 기능 검증

- 에디터 전용 검증 기능: 플레이어 컨트롤러의 `bDebugPointerOverride`/`DebugPointerPosition`으로 UI 판정에 쓰는 마우스 위치를 정하고, `bDebugLeftClick`·`bDebugRightClick`·`bDebugPing`·`bDebugToggleShop`·`bDebugToggleGameMenu`·`bDebugShowScoreboard`로 실제 입력과 같은 코드 경로를 실행한다. HUD의 `LastCanvasSize`로 화면 크기를 읽어 버튼 위치를 계산한다. Shipping에는 들어가지 않는다.
- 이 방법과 화면 캡처로 확인한 것: 상점 줄 클릭으로 구매(골드 -350), 가방 칸 클릭으로 판매(+245), 스킬 툴팁, 점수판, F10 메뉴(항복 잠김 표시, 계속하기로 닫힘), 미니맵 좌클릭으로 카메라 이동, 미니맵 우클릭으로 이동 명령, 핑(지면 원과 미니맵 점), 로비 챔피언 버튼과 준비 버튼(준비 뒤에는 챔피언이 바뀌지 않음).
- 고친 것: 툴팁이 미니맵에 가려지던 것(그리는 순서), 미니맵 위 핑이 미니맵 배경에 덮여 안 보이던 것(그리는 순서).
- 아직 직접 확인하지 못한 것: 실제 키보드 단축키 자체(Tab, P, B, F10, Alt, 4)가 눌리는지와 화면 모드·해상도 버튼이 실제 창을 바꾸는지. F10 메뉴는 창 높이가 약 750픽셀보다 작으면 아래쪽 조작 안내가 잘린다.

자동화 테스트와 배포용 빌드

- **자동화 테스트**: `Source/ver1/Tests/MobaRulesTests.cpp`에 8개(`Moba.Rules.*`, `Moba.Data.*`). 피해 감소 공식, 처치 현상금, 레벨별 부활 시간, 미니언 성장, 경험치 곡선, 궁극기 배우는 레벨, 아이템 목록, 정글 캠프 구성을 확인한다. 수치를 바꾸면 테스트의 기대값도 같이 바꿔야 한다.
- **실행**: 에디터를 닫고 `Tools/RunTests.bat`. 에디터 안에서는 도구 → 세션 프론트엔드 → 자동화에서 "Moba"로 찾는다.
- **패키징**: `Tools/Package.bat`(로그가 있는 Development, `Saved/Packaged`) 또는 `Tools/Package.bat Shipping`(배포용, `Saved/PackagedShipping`). 친구에게 줄 때는 Shipping을 쓴다. 디버그용 훅과 `-MobaForceLobby`는 Shipping에서 빠진다.
- **Shipping의 차이**: 엔진이 배포용 빌드에서는 명령줄의 맵·접속 주소를 무시하므로 항상 메인 메뉴에서 시작하고, 로그 파일도 남기지 않는다.
- **바로 시작 인자**: `-MobaHost`는 메뉴가 뜨자마자 방을 만들고, `-MobaJoin=주소`는 바로 접속한다(Development·Shipping 모두). 바탕화면 바로가기의 대상 뒤에 붙여 쓰면 된다.
- **확인한 것**: 테스트 8개 통과. Development 클라이언트 → Shipping 호스트(`-MobaHost`), Shipping 클라이언트(`-MobaJoin`) → Development 호스트 모두 접속 성공.
- **고친 것**: 미니언 사망 애니메이션이 코드에서 경로로만 참조돼 패키지에 빠져 있었다. `Characters/Mannequins/Anims/Death` 폴더를 항상 쿠킹하도록 했다.

UI 편의

- **피해량 숫자**: 챔피언·몬스터·건물이 피해를 받으면 그만큼의 숫자가 머리 위로 1초 동안 떠오른다. 내 챔피언이 받은 피해는 빨간색. 체력이 줄어든 양을 보고 그리므로 각 PC에서 따로 계산하며, 시야 밖의 유닛은 보이지 않는다. 미니언은 숫자가 너무 많아져서 뺐다.
- **스킬 툴팁**: 스킬 칸에 마우스를 올리면 이름·단계, 설명, 마나, 재사용 대기 시간, 사거리를 보여 준다. 설명은 각 스킬 클래스의 `Description`.
- **화면 설정**: 메인 메뉴와 F10 게임 메뉴에서 창 모드·전체 화면(테두리 없는 창)과 해상도(1280x720, 1600x900, 1920x1080, 2560x1440)를 바꿀 수 있다. 엔진의 게임 사용자 설정에 저장돼 다음 실행에도 유지된다. 에디터 PIE에서는 창이 바뀌지 않는다.
- **조작 안내**: F10 게임 메뉴 아래에 주요 키를 적어 두었다.

규칙 보강

- **부활 시간**: 1레벨 5초에서 레벨당 2.5초씩 늘고 최대 50초(`RespawnDelay`, `RespawnDelayPerLevel`, `MaxRespawnDelay`).
- **처치 현상금**: 기본 300G. 2연속 이상 처치 중인 챔피언을 잡으면 연속 1회당 +150G(최대 1000G). 2연속 이상 죽고 있는 챔피언은 1회당 -50G(최소 100G). 기본과 다르면 처치 알림에 현상금이 붙고, 3연속 처치부터는 "N연속 처치!" 알림이 뜬다.
- **어시스트**: 처치 직전 10초 안에 피해를 준 아군이 어시스트를 받고 현상금의 절반을 나눠 받는다. 1대1에서는 생기지 않는다. 점수판과 결과 화면은 K/D/A로 보여 준다.
- **미니언 성장**: 경기 시간 90초마다 새로 나오는 미니언의 체력 +5%, 공격력 +4%, 보상 골드 +2%(최대 20회).
- **항복**: F10 게임 메뉴에서 경기 3분 뒤부터 누를 수 있다. 팀 전원이 동의하면 그 팀의 패배로 끝나고, 결과 화면에 항복했다고 표시된다. 같은 메뉴의 "메뉴로 나가기"는 경기 중이면 상대의 승리(이탈)로 처리된다.

로비와 결과 화면 (6단계 보강)

- 메뉴에서 "방 만들기"로 연 방(접속 주소에 `Players=2`)은 경기 전에 로비를 거친다. 에디터 PIE와 "혼자 연습"은 거치지 않고 바로 시작한다.
- 로비 동안에는 챔피언과 미니언이 나오지 않는다. 화면에 참가자(팀, 챔피언, 준비 여부), 내 챔피언 버튼, 준비 버튼이 보이고 호스트에게는 상대에게 알려 줄 주소가 함께 보인다. 메뉴에서 고른 챔피언이 처음 값이고, 준비를 누르면 바꿀 수 없다(준비 취소 후 변경).
- 인원이 차고 모두 준비되면 3초 카운트다운 뒤 고른 챔피언으로 생성되며 경기가 시작된다. 카운트다운 중 누가 준비를 풀거나 나가면 멈춘다. 시작된 경기에는 새로 접속할 수 없다("이미 시작된 경기입니다").
- 경기가 끝나면 승패, 경기 시간과 함께 플레이어별 챔피언·레벨·K/D·CS·챔피언에게 준 피해량·아이템 표가 뜬다. 같은 표를 Tab 점수판에도 쓴다.
- 에디터에서 로비를 시험하려면 에디터를 `-MobaForceLobby` 인자로 실행한다. 그러면 PIE에서도 2인 로비를 거친다.

네트워크 품질 (6단계 보강)

- **서버 쪽 시야 차단**: 서버가 팀마다 볼 수 없는 유닛을 0.1초마다 계산하고(`MobaVisionSubsystem`), 상대 팀이 볼 수 없는 챔피언·미니언·몬스터·와드는 그 팀의 PC로 보내지 않는다(`IsNetRelevantFor`). 그래서 클라이언트를 변조해도 안개 속 적의 위치를 알 수 없다. 시야에서 벗어난 유닛은 약 1초 뒤 상대 PC에서 사라진다(`RelevantTimeout=1.0`). 건물과 투사체는 계속 보낸다.
- **한계**: 방을 만든 호스트는 서버를 겸하므로 모든 정보를 가지고 있다. 완전히 공정하게 하려면 별도의 데디케이티드 서버가 필요하다.
- **시전 반응**: 조종하는 클라이언트는 스킬을 누르는 즉시 시전 동작과 이펙트를 먼저 보여 주고, 서버의 알림이 오면 다시 재생하지 않는다. 단계·쿨다운·마나가 모자라 실패할 시전은 미리 걸러 동작을 보여 주지 않는다. 피해와 효과는 여전히 서버가 정한다.
- **지연 시험**: PIE 네트워크 에뮬레이션으로 왕복 약 160ms, 패킷 손실 2%를 걸고 이동·기본 공격·스킬·시야를 확인했다. 모두 동작했고, 이동이 끝난 뒤 서버와 클라이언트의 위치 차이는 약 20cm였다. 시험 뒤 에뮬레이션은 다시 껐다(에디터 설정 → 에디터에서 플레이 → 네트워크 에뮬레이션에서 켤 수 있다).

구현 메모

- **라인**: 세 라인 모두 30초마다 근접 3 + 원거리 3이 나온다.
- **억제기**: 파괴되면 5분 뒤 다시 생긴다(`RespawnDelay`). 파괴돼 있는 동안 그 라인의 상대 웨이브에 슈퍼 미니언이 1마리(세 억제기가 모두 파괴돼 있으면 2마리) 섞인다. 억제기가 하나도 파괴돼 있지 않으면 넥서스 타워는 다시 무적이 된다.
- **정글**: `MobaJungleCamp`를 레벨에 놓고 `CampType`만 고르면 된다. 구성과 시간은 `AMobaJungleCamp::GetDefinition`에 있다. 일반 캠프는 1:30에 나와 2:15마다, 버프 캠프는 5:00마다, 바위게는 3:30에 나와 2:30마다, 드래곤은 5:00에 나와 5:00마다, 바론은 20:00에 나와 6:00마다 재생성된다. 수치는 프로토타입 챔피언 혼자 잡을 수 있게 낮춘 값이다.
- **몬스터**: 팀은 `Neutral`. 챔피언하고만 싸우고 미니언·타워와는 서로 무시한다. 자기나 같은 캠프의 몬스터가 맞으면 반격하고, 캠프에서 800 넘게 끌려가면 돌아가 체력을 채운다. 골드와 경험치는 막타를 친 챔피언만 받는다.
- **보상**: 블루(2분) 마나 재생 +6/초, 재사용 대기 10% 감소. 레드(2분) 초당 최대 체력의 0.5% 회복, 기본 공격에 고정 피해 12와 15% 둔화. 블루·레드·바론은 죽으면 사라진다. 드래곤은 팀 전원에게 공격력 10·주문력 15를 경기 끝까지 주고 잡을 때마다 겹친다. 바론은 살아 있는 팀원에게 3분간 공격력·주문력 40과 팀 골드 300. 바위게는 잡은 자리에 90초 동안 시야를 준다.
- **시야**: `MobaVisionSubsystem`이 각 PC에서 자기 팀이 볼 수 있는 것을 0.1초마다 계산한다. 아군 챔피언(1350)·미니언(1100)·건물(1300)·와드(1000)가 시야를 준다. 벽 너머와, 아군 시야가 같은 부쉬에 들어가 있지 않은 부쉬 안의 적은 숨겨지고 체력바·미니맵에서도 빠지며 클릭·자동 공격 대상이 되지 않는다. 쫓던 적이 시야에서 사라지면 공격을 멈춘다. 적 건물은 항상 보인다.
- **시야의 한계**: 숨김은 화면 표시에만 적용된다. 위치 정보는 계속 복제되므로 변조된 클라이언트는 볼 수 있다. 스킬과 타워·미니언의 판정은 시야와 무관하다.
- **부쉬**: `MobaBush` 상자를 그레이박스 부쉬 표시물과 같은 위치·크기로 놓았다(`Gameplay/Bushes`). 표시물을 옮기면 상자도 같이 옮겨야 한다.
- **미니맵**: 화면 오른쪽 아래. 월드 +X가 위, +Y가 오른쪽이라 블루 기지가 왼쪽 아래다. 라인, 건물, 살아 있는 캠프, 미니언, 챔피언, 아군 와드, 현재 화면 범위를 그린다.

검증한 것 (PIE, 서버 쪽 상태 조회): 3라인 웨이브, 캠프 스폰과 재생성 시간, 몬스터 반격·복귀·회복, 블루·레드 버프와 레드의 둔화, 드래곤 보상 중첩, 와드 설치와 재사용 대기, 호스트·접속자 양쪽의 시야 숨김(거리, 부쉬, 같은 부쉬), 억제기 파괴 → 넥서스 타워 무적 해제 → 슈퍼 미니언 → 억제기 재생성 → 넥서스 타워 재보호, 넥서스 파괴로 경기 종료.

검증하지 못한 것: HUD와 미니맵이 실제로 어떻게 보이는지, 미니맵 클릭과 4번 키 입력, 바론 보상과 바위게 시야(드래곤과 같은 코드 경로지만 직접 잡아 보지는 않음), 벽에 의한 시야 차단, 패키지 빌드에서의 동작.

완료 기준: 3라인과 정글이 모두 동작하고 한 판이 정상 종료된다.

- **뱅가드** (`DA_Champion_Vanguard`): 근접. Q 돌진 베기(도착 지점 주변 물리 피해와 0.75초 침묵), W 재정비(잃은 체력에 비례해 회복), E 지면 강타(주변 물리 피해와 0.75초 에어본), R 전투 광분(이동·공격 속도 증가). 임시 외형은 더 굵고 낮은 원기둥이다.

- **섀도우** (`DA_Champion_Shadow`): 근접 암살자. Manny 마네킹에 거의 검은 머티리얼(`MI_Champion_Shadow`). Q 그림자 찌르기(커서 근처 적 등 뒤로 순간이동해 물리 피해, 이동 스킬이라 속박에 막힘), W 그림자 숨기(3초 은신과 20% 가속), E 연막탄(범위 물리 피해와 1.5초 40% 둔화), R 처형(대상 챔피언에게 큰 물리 피해와 잃은 체력의 30% 추가). 패시브 암습: W 뒤 첫 기본 공격에 공격력 50% 추가 물리 피해.

- 대상 지정 스킬(섀도우 Q·R, 점화·강타)은 `MobaAbility::PickEnemyNearCursor`로 커서 근처의 보이는 적 하나를 고른다.
- **패시브**: 챔피언 데이터의 `Passive`에 `UMobaPassive` 하위 클래스를 지정한다(`Character/MobaPassive.h`). 서버에서만 인스턴스가 만들어지고 챔피언이 기본 공격·스킬 발동·피해·0.25초 틱·부활을 알려 준다. 기본 공격 때는 추가 물리·마법 피해와 마나 회복을 돌려줄 수 있다. 화면 표시용 중첩 수(`PassiveStacks`)만 복제된다. HUD에는 Q 칸 왼쪽에 패시브 칸(중첩 수 또는 ON)이 있고, 올리면 이름과 설명이 뜬다.
  - 레인저 **연발 사격**: 기본 공격 세 번째마다 공격력의 40% 추가 물리 피해.
  - 뱅가드 **불굴**: 5초 동안 피해를 받지 않으면 1초에 최대 체력 1.5% 회복.
  - 미스틱 **마력 충전**: 스킬을 쓰면 다음 기본 공격이 마법 피해 30(+주문력 40%)을 더하고 마나 15 회복.
- **2대2**: 메인 메뉴의 "방 만들기" 옆 버튼으로 1대1/2대2를 바꾼다(저장됨). 2대2면 로비가 4명을 기다린다. 들어온 순서대로 블루·레드를 번갈아 배정하고, 팀마다 시작 지점이 하나라 같은 팀 두 번째 플레이어부터는 시작 지점 둘레(180)에 비켜 생성·부활한다(`GetTeamSlotOffset`). 시야는 팀 단위로 함께 쓰고, 어시스트(현상금의 50%를 나눔), 미니언이 깬 포탑 방패 골드 나누기, 팀 전원 동의 항복, 팀 전원 이탈 시 패배가 그대로 적용된다. 로비 없이(에디터·연습) 받을 수 있는 인원은 4명. 셋 이상이거나 낮은 창이면 로비 줄과 버튼을 낮춰 화면에 다 들어가게 했다. 개발 빌드는 `-MobaForceLobby -MobaLobbyPlayers=4`로 4인 로비를 시험할 수 있다.
- **군중 제어**: 둔화·기절 외에 속박(이동과 돌진·순간이동 스킬만 막힘, 공격·다른 스킬은 됨), 침묵(스킬만 막힘, 소환사 주문·이동·공격은 됨), 에어본(기절처럼 모두 막힘)이 있다. 스킬의 `bMovementAbility`(점멸 계열·돌진)가 속박에 막히는 기준이고, 걸린 상태는 챔피언 체력바 위에 "공중에 뜸/기절/속박/침묵" 중 가장 강한 것 하나로 보인다. `MobaAbility::MakeCrowdControlSpec`으로 건다. 속박 중에는 사거리 밖 대상을 쫓지 않는다. 미니언·몬스터도 `MobaCombat::BindUnitMovement`로 이동 속도 능력치(둔화·가속)를 걷는 속도에 반영하고, 기절·에어본·속박 중에는 멈춘다(예전에는 생성 때 속도로 고정되어 둔화도 기절도 이동에 영향이 없었다).
- **개발자 명령**: 에디터와 Development 빌드에서 콘솔(` 키)에 입력한다. 배포(Shipping) 빌드에서는 아무 일도 하지 않는다. 쓰면 모두에게 "[개발] …" 알림이 뜬다.
  - `MobaGold 1000`: 골드를 준다.
  - `MobaLevel 11`: 그 레벨까지 올린다(스킬 포인트 포함).
  - `MobaSkipTime 600`: 경기 시간을 앞당긴다. 정글 출현·전령 소멸·미니언 성장·포탑 방패 소멸에 반영된다(웨이브 간격은 그대로).
  - `MobaRefresh`: 체력·마나를 채우고 스킬·소환사 주문 재사용 대기를 없앤다.
  - `MobaSpawnCamps`: 비어 있는 정글 캠프(드래곤·바론·전령 포함)를 바로 내보낸다.
- **드래곤 원소**: 드래곤은 나올 때마다 화염·대지·바람·바다 중 하나로 정해지고(처치 직후 다음 원소를 미리 정함), 타이머 위에 "바다 드래곤"처럼 다음 원소가 보인다. 처치한 팀 전원(죽어 있어도)이 영구히 받는 보상은 원소마다 다르고 중첩된다: 화염 공격력 +10·주문력 +15, 대지 방어력·마법 저항력 +6, 바람 이동 속도 +10, 바다 초당 최대 체력 0.4% 재생. 버프 표시는 "화염 용 x2"처럼 원소별로 보인다. 정글 버프 효과는 방어력·마법 저항력·이동 속도도 더할 수 있게 넓혔다(`MobaAbility::MakeStatBuffSpec`).
- **협곡의 전령**: 바론 둥지 옆 캠프(`CampType` Herald)에 8:00에 나오고, 잡히면 6분 뒤 다시 나오며, 19:45가 되면 살아 있어도 보상 없이 사라진다(캠프 정의의 `DespawnTime`). 체력 5000. 막타를 친 챔피언은 "전령의 눈"(4분)을 얻고 키 2로 쓴다. 쓰면 가장 가까운 라인(1500 이내) 위에 아군 전령(미니언 종류 Herald)이 90초 동안 소환되어 라인을 따라 걸으며 건물만 공격한다(체력 3000, 공격력 400). 전령을 잡으면 골드 100, CS에는 넣지 않는다. 눈을 들고 있으면 제어 와드 칸 오른쪽에 남은 시간이 보인다.
- **사망 요약**: 죽으면 부활 카운트다운 아래에 처치한 쪽과, 최근 10초 동안 받은 피해를 준 쪽별 합계(많은 순 최대 5줄, 비율 막대)가 보인다. 서버가 챔피언이 받은 피해를 10초만 모아 두었다가 죽을 때 그 플레이어에게만 보낸다(`SendDeathRecap`).

- **선취점**: 경기의 첫 챔피언 처치(챔피언이 막타)는 현상금에 100G를 더 받고 "선취점!" 알림이 뜬다. 포탑·미니언에게 죽은 것은 치지 않는다.
- **포탑 방패**: 외곽 포탑(앞에 지켜 주는 건물이 없는 라인 첫 포탑, 6개)은 경기 시작 후 14분까지 방패 5개를 가진다. 방패 하나는 최대 체력의 20%이고, 체력이 80·60·40·20·0% 경계를 넘을 때마다 하나씩 깨지며 160G를 준다. 깬 것이 챔피언이면 그 챔피언이, 미니언이면 1200 안의 상대 챔피언들이 나눠 받는다. 포탑 체력바에 방패 수만큼 눈금이 보인다. 14분이 되면 방패가 모두 사라지고 알림이 뜬다(`TowerPlatingDuration`).
- **보호막**: 능력치 `Shield`가 피해를 체력보다 먼저 흡수한다. 처치 기여·생명력 흡수·귀환 끊김은 흡수된 몫까지 포함한 피해로 본다. 보호막은 `AMobaCharacter::AddShield(양, 시간)`으로 주고, 여러 개면 먼저 사라질 것부터 깎이며 시간이 지나거나 죽으면 사라진다(0.25초마다 정리하므로 능력치를 직접 바꾸면 곧 지워진다). 체력 바에는 체력 뒤에 흰색으로, 아래 체력 수치에는 "(+보호막)"으로 보인다.
- **소환사 주문**: 로비의 "소환사 주문" 줄에서 D·F 칸에 하나씩 고른다(다른 칸에 있는 주문을 고르면 두 칸이 바뀐다). 로비 없이 시작하면 점멸·점화다. 참가자 목록에 서로의 주문이 보인다. 스킬과 같은 GAS 경로(`EMobaAbilitySlot::D/F`)로 처음부터 1단계로 주어지며, 스킬 포인트로 올릴 수 없고 마나를 쓰지 않으며 패시브의 "스킬을 쓰면" 효과를 일으키지 않는다. 화면에는 R 칸 오른쪽에 작은 D·F 칸이 있다. 코드는 `AbilitySystem/Abilities/MobaSummonerSpells.*`.
  - 점멸 400 순간이동(300초), 회복 80+레벨당 15와 1초 30% 가속(240초), 점화 사거리 600 적 챔피언에게 5초 동안 고정 피해 70+레벨당 20(180초), 유체화 10초 40% 가속(210초), 강타 사거리 500 몬스터·적 미니언에게 고정 피해 600(90초), 방어막 2.5초 동안 95+레벨당 15 보호막(180초).
  - 점화와 강타는 커서 근처(300) 대상 중 커서에 가장 가까운, 시야 안의 알맞은 대상을 고른다. 사거리 안에 없으면 아무것도 쓰지 않고 취소된다.
  - 메인 메뉴에도 "소환사 주문 D: … F: …" 버튼이 있고 누를 때마다 다음 주문으로 바뀐다. 고른 주문은 접속 옵션 `?Spells=Flash,Smite`(D, F 순서)로 서버에 전달되므로 로비 없는 혼자 연습에서도 적용된다.
- **구성 저장**: 메뉴나 로비에서 고른 챔피언과 소환사 주문은 저장 슬롯 `MobaProfile`(`UMobaProfileSave`)에 저장되어 다음 실행 때 그대로 쓰인다. 패키지에서는 `Windows/ver1/Saved/SaveGames/MobaProfile.sav`. 개발 빌드는 `-MobaChampion=에셋이름`, `-MobaSpells=Smite,Heal` 인자로 고른 것처럼 정할 수 있다(검증용, 배포 빌드에서는 무시).

  - **제어 와드**(소모품, 75G, 최대 2개): 키 3으로 놓는다. 시간 제한이 없고 한 사람당 하나만 맵에 남는다(새로 놓으면 이전 것이 사라짐). 반경 900 안의 적 일반 와드를 드러내고 그 와드의 시야를 끈다. 제어 와드 자신은 시야 안의 적에게 보인다.
  - **와드 부수기**: 와드는 클릭해서 기본 공격으로만 부술 수 있다. 피해량과 상관없이 한 번에 1씩(일반 3번, 제어 4번) 깎이고 스킬 피해는 받지 않는다. 부순 챔피언은 30G. 미니언·포탑·자동 공격은 와드를 노리지 않는다(와드는 물리 물체 종류라 대상 찾기에 걸리지 않는다). 보이는 와드 위에 남은 횟수가 칸으로 보인다.
  - **체력 물약**(소모품, 50G): 가방 칸을 쓰지 않고 최대 5개까지 쌓인다. 키 1로 마시면 15초 동안 체력 120을 회복하고, 마시는 중에 또 마시면 회복이 이어진다. 죽으면 남은 회복은 사라진다. 와드 칸 위에 개수가 보이고 마시는 중에는 초록색이다.
  - **생명력 흡수·스킬 가속**: 능력치(`LifeSteal`, `AbilityHaste`)로 추가했다. 흡혈은 기본 공격 피해에만 걸린다(피해 스펙에 `Damage.BasicAttack` 태그). 스킬 가속은 재사용 대기를 100/(100+가속)배로 줄이고 블루 버프와 곱해지며, 소환사 주문에는 걸리지 않는다. 흡혈의 홀(긴 검 재료, 흡혈 10%), 마력의 보주(+15), 대마법사의 모자(+20)에 붙였다. 스킬 툴팁은 가속이 반영된 재사용 대기를 보여 준다.
- **능력치 패널**: 화면 왼쪽 아래에 공격력·주문력·방어력·마법 저항·공격 속도·이동 속도·스킬 가속·흡혈을 두 열로 보여 준다. 좁은 화면에서 스킬 바와 겹치면 그 위로 올라간다.
  - 상점은 왼쪽 기본, 오른쪽 완성 두 열이고, 완성 아이템에는 재료와 지금 낼 가격(싸졌으면 원래 가격을 괄호로)이 보인다. 폭이 약 770이라 640 폭 창에서는 잘린다.
- **알림**: 챔피언 처치, 건물 파괴, 억제기 재생성, 드래곤·바론 처치가 화면 오른쪽 위에 7초 동안 뜬다. 화면 위쪽 가운데에는 팀 처치 수 합계와 내 K/D/CS가 표시된다.
- **대상을 지정하지 않는 스킬**(가속, 회복, 지면 강타 등)은 서버가 아는 시전자 위치에서 발동한다. 클라이언트가 보낸 위치는 쓰지 않는다.

임시 아트 (Epic 마네킹)

- 엔진에 포함된 마네킹 팩(`Templates/TemplateResources/High/Characters`)을 `Content/Characters`에 복사했다. 에디터의 "기능 또는 콘텐츠 팩 추가 → Characters"와 같은 내용이다.
- 레인저는 Quinn, 뱅가드는 Manny. 이동은 `BS_Idle_Walk_Run` 블렌드 스페이스(속도 축), 기본 공격은 `MM_Attack_01~03`을 돌아가며, 스킬은 칸별로 공격·돌진(`MM_Dash`)·차지 공격, 사망은 `MM_Death_Front_01`.
- 애니메이션 블루프린트 없이 `MobaAnimationComponent`가 단일 노드 모드로 직접 재생한다. 공격 동작은 공격 주기 안에 끝나도록 빨라지고, 걷기 시작하면 끊긴다. 죽으면 쓰러지는 모습을 2.5초 보여 준 뒤 숨긴다.
- 메시가 있으면 임시 원기둥은 발밑의 팀 색 원판이 된다.
- 챔피언 데이터 에셋의 `Animations` 항목에서 애니메이션을 바꿀 수 있다. 애니메이션 블루프린트(`AnimClass`)를 지정하면 그쪽이 우선한다.

- 미니언도 마네킹을 줄여 쓴다(근접 Manny 0.58배, 원거리 Quinn 0.55배, 슈퍼 Manny 0.85배). 외형은 `MobaGameMode` 생성자의 미니언 설정에 들어 있고, 접속한 쪽은 복제된 미니언 종류를 보고 게임 모드 기본값에서 찾는다. 죽으면 1.3초 동안 쓰러지는 동작을 보여 주고 사라진다.

전장의 안개 표시

- 시야 계산(`MobaVisionSubsystem`)이 맵을 96×96 격자로 나눠 꼭짓점마다 아군 시야 안인지 0.1초마다 칠한다. 시야 원과 부쉬만 보고 벽은 고려하지 않는다(유닛을 숨기는 판정은 벽까지 본다).
- HUD가 화면에 보이는 칸만 골라 시야 밖 꼭짓점을 어둡게(불투명도 `FogOpacity` 0.55) 삼각형으로 덮는다. 꼭짓점마다 투명도가 달라 가장자리가 부드럽다. 미니맵에도 같은 격자를 두 칸씩 묶어 그린다.
- 기본 카메라 거리에서는 시야 반경(1350)이 화면과 비슷해서 안개가 화면 가장자리에만 보인다. 휠로 멀리 빼면 잘 보인다.

맵 1차 다듬기

- 엔진 템플릿의 레벨 프로토타이핑 팩(`Templates/TemplateResources/High/LevelPrototyping`)을 `Content/LevelPrototyping`에 복사했다.
- 회색 박스 맵의 모든 벽·바닥·강·부쉬·기지 바닥·캠프 표시는 `Content/Maps/Graybox`의 머티리얼 인스턴스 7개(`MI_Graybox_*`)를 쓴다. 이 인스턴스들의 부모를 `M_PrototypeGrid`(월드 기준 격자)로 바꾸고 색과 격자 크기를 정했다. 바닥은 짙은 녹색, 벽은 갈색, 강은 남색, 부쉬는 밝은 녹색이다. 색은 각 인스턴스의 `SurfaceColor`/`TopSurfaceColor`와 `Grid Size`로 바꾼다.
- 맵 전체에 적용되는 후처리 볼륨(`GlobalPostProcess`, Lighting 폴더)을 넣고 자동 노출을 -0.6 낮췄다. 밝은 바닥 때문에 화면이 바래 보이던 것을 줄인다.
- 실제 지형·건물 메시와 조명 연출은 에셋을 정한 뒤 진행한다.

이펙트와 사운드

- 게임 코드는 효과의 종류(`EMobaEffect`: 명중, 유닛 사망, 건물 파괴, 스킬 시전, 범위 폭발, 레벨업)만 정하고, 무엇을 재생할지는 프로젝트 설정의 "Moba Effects"(`UMobaEffectSettings`, DefaultGame.ini)에서 고른다. 효과마다 나이아가라 시스템, 크기 배율, 소리를 지정한다.
- 기본값은 `Content/Effects`의 임시 이펙트 4개다. 엔진 템플릿(RadialBurst, SimpleExplosion, DirectionalBurst)으로 만들고, 탑다운 카메라 거리에서 보이도록 입자 크기만 키웠다(템플릿 그대로면 2~6cm라 화면에서 1~2픽셀). 소리는 비어 있으니 효과음 에셋을 넣고 설정의 Sound에 지정하면 된다.
- 재생은 각 PC에서 따로 한다(화면 없는 서버에서는 하지 않는다). 시야 밖이라 숨겨진 유닛의 이펙트는 보이지 않는다.
- 언제 나오는지: 기본 공격 투사체가 대상에 닿을 때, 스킬샷이 무언가에 맞을 때, 챔피언·미니언·몬스터가 죽을 때, 건물이 파괴될 때, 스킬이 발동될 때(시전자 발밑), 범위 폭발 표시가 끝나는 순간, 레벨이 오를 때.

고친 것: 스킬 단계를 올려도 조종하는 클라이언트에는 단계가 0으로 남아 HUD에 0/5로 보였다(5단계부터). 서버 전용 스킬은 엔진이 스펙 변경을 복제 대상으로 표시하지 않기 때문이었고, 단계를 올릴 때 강제로 복제하도록 바꿨다.

고친 것: 임시 도형(원기둥·상자·구)이 엔진 기본 머티리얼로 그려져 팀 색이 3D 화면에 적용되지 않고 있었다. 1단계부터 있던 문제로, 모든 임시 도형에 `Color` 파라미터가 있는 `BasicShapeMaterial`을 쓰도록 바꿨다. 레벨에 저장돼 있던 건물의 예전 머티리얼도 실행 시 바로잡는다.

에셋을 넣을 때

1. 스켈레탈 메시와 애니메이션을 임포트한다.
2. `MobaAnimInstance`를 부모로 애니메이션 블루프린트를 만든다. `Speed`, `bIsMoving`, `bIsDead`, `bIsStunned`, `bIsRecalling` 변수가 매 프레임 채워지고, `OnBasicAttack`(기본 공격 시작)과 `OnAbilityCast`(스킬 발동, 칸 번호 포함) 이벤트가 온다. 값의 변화로 전이를 걸고 싶으면 `AttackCount`, `AbilityCastCount`, `LastAbilitySlot`을 쓴다. 미니언과 몬스터에도 같은 부모를 쓸 수 있다(스킬 이벤트는 챔피언만).
3. 챔피언 데이터 에셋의 `Mesh`, `AnimClass`를 지정하고 `MeshOffset`(보통 Z를 캡슐 절반 높이만큼 내림), `MeshRotation`(보통 요 -90), `MeshScale`을 맞춘다. 메시가 지정되면 임시 원기둥은 자동으로 숨는다.
4. 미니언·몬스터·건물·투사체는 아직 임시 도형만 쓴다. 메시를 붙이려면 각 클래스에 같은 방식의 연결부를 추가해야 한다.

검증한 것 (PIE, 서버 쪽 상태 조회): 순서대로 다른 챔피언이 배정되고 스탯·스킬이 맞게 들어가는 것, 아이템 구매·판매와 수치 반영, 골드 부족·우물 밖·중복 장화 거절, 귀환 완료와 이동 시 취소, 접속자 쪽에서 쓴 뱅가드의 Q·W·E·R.

검증한 것 (패시브, PIE): 미스틱 Q 적중 피해 69(방어 반영), 스킬 뒤 기본 공격 피해 59(평소 37)와 마나 +15 후 충전 해제, 레인저 세 번째 공격 67(평소 47)과 중첩 0→1→2→0, 패시브 칸 ON 표시와 툴팁, 미스틱 보라색 외형. 뱅가드 불굴은 코드와 데이터만 확인.

검증한 것 (드래곤 원소, PIE): 드래곤을 7번 잡으며 화염(공격력 +10·주문력 +15), 바람(이동 속도 +10), 대지(방어력·마저 +6), 바다(최대 체력 50190에서 초당 약 198 재생) 보상과 원소 태그, 처치 뒤 다음 원소가 바뀌는 것.

검증한 것 (섀도우·은신, PIE): 로비에서 호스트 섀도우·접속자 레인저. W 동안(0.3~2.2초) 레드 PC로 섀도우가 전송되지 않고 풀린 뒤 다시 보임, 기본 공격 시 은신 해제와 암습(첫 타 92.4, 다음 60.2), Q로 레인저 등 뒤(9800→9890)로 이동하며 188.5 피해, R로 체력 238인 레인저에게 238 피해, 레드 제어 와드 근처에서는 은신 중에도 계속 보이고 와드를 부수자 다시 숨겨짐.

검증한 것 (개발자 명령, PIE): 접속자 콘솔에서 MobaSpawnCamps(몬스터 0→31), MobaGold 1000, MobaLevel 11(스킬 포인트 11), MobaRefresh(레인저 Q 재사용 대기 제거), 호스트 MobaSkipTime 470/720, 모두에게 "[개발]" 알림.

검증한 것 (협곡의 전령, PIE): 전령 캠프에 체력 5000 몬스터 생성, 처치하자 전령의 눈(만료 시각) 획득, 미드 라인에서 사용하자 눈이 사라지고 전령이 소환되어 레드 외곽 포탑을 2초마다 약 286씩 깎음. 소환 전령을 잡았을 때의 보상은 확인하지 못했다. (개발 명령으로) `MobaSkipTime`으로 20분을 넘기자 전령이 사라지고 바론만 남음, 14분을 넘기자 외곽 포탑 방패가 0이 됨.

검증한 것 (사망 요약·골드 표시, PIE): 뱅가드가 레인저를 처치하자 뱅가드 위에 "+400G", 블루 포탑 근처에서 레인저와 포탑에게 죽은 뱅가드 화면에 "처치: 블루 레인저", 받은 피해 420, 블루 타워 245·블루 레인저 174. 능력치 패널·미니맵에 가리지 않도록 그리는 순서를 뒤로 옮겼다.

검증한 것 (제어 와드, PIE): 레드 일반 와드는 블루 화면에서 숨겨져 있고 레드는 그 와드로 레인저를 봄 → 블루가 제어 와드를 놓자 레드 와드가 블루에게 드러나고 레드는 레인저를 더 이상 받지 못함, 블루 제어 와드는 레드 시야가 없어 레드에게 보이지 않음, 드러난 와드를 기본 공격 3번에 부수고 30G, 제어 와드 4칸 체력 표시와 "3 제어" 칸.

검증한 것 (체력 물약, PIE): 6번 사면 5개에서 멈추고 250G 차감, 마실 때마다 개수 감소, 두 개 연달아 마시면 남은 회복량 240, 레인저 기준 초당 약 8.9 회복(물약 8 + 재생 1.4), 와드 칸 위 물약 칸 표시.

검증한 것 (미니언 이동, PIE): 라인을 걷던 근접 미니언이 레인저 R 기절 동안 0.4초에 이동 0, 풀린 뒤 초속 약 307로 다시 걸음, 레인저 Q 둔화 동안 걷는 속도 325→227.5, 끝나면 325.
